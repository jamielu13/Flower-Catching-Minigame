# Flower Catching Minigame

A cute 2d minigame built from scratch using Java. 
The player is a princess wielding a net, trying to catch flowers falling from the sky. 
* **Scoring:** Gain a point per flower caught
* **Lives:** Missing a flower loses a life
* **Game Over:** No more lives Game Over

**How to Play:**
* Run the Main.class to open up the frame.
* a: move left
* d: move right

**Artwork**
* Artwork and assets were entirely self drawn.
